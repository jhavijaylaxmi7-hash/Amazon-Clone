# 🛒 Amazon Clone

A responsive Amazon Homepage Clone built using **HTML5** and **CSS3**. This project recreates the user interface of the Amazon homepage with a clean and modern design. It is a frontend-only project developed to practice HTML and CSS skills.

> **Note:** This project is created for educational purposes only and is not affiliated with or endorsed by Amazon.

---

## 📌 Project Overview

This project is a static clone of the Amazon homepage that focuses on replicating its layout, design, colors, and overall appearance. It helps in understanding the fundamentals of frontend web development and responsive web design.

---

## ✨ Features

- 🏠 Amazon-style homepage layout
- 🔍 Search bar user interface
- 🧭 Responsive navigation bar
- 🖼️ Hero banner section
- 📦 Shopping category boxes
- 🛍️ Product showcase sections
- 📱 Responsive design
- 🎨 Clean and modern UI
- 💻 Built using only HTML and CSS
